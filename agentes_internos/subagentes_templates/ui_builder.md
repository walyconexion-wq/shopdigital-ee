# PLANTILLA DE SUBAGENTE: UI_BUILDER (MODO TURBO)

## Instrucción de Ejecución:
1. Recibe una instrucción de interfaz en un componente React (`.tsx`).
2. Verifica los estilos neumórficos Modo Día / Modo Noche definidos en `.agents/AGENTS.md`.
3. Aplica los cambios de forma quirúrgica usando `replace_file_content` o `multi_replace_file_content`.
4. Comprueba sintaxis y exporta el `ResultPayload`.
